# Python Zero to Hero Learning Path

This repository is organized as a step-by-step Python learning roadmap, from beginner fundamentals to intermediate application-building concepts. Each topic is designed as a branch-based milestone so you can progress in a clean, practical order.

## Recommended Learning Order

This guide moves from foundational Python skills to real-world backend development and deployment.

1. Beginner topics
2. Intermediate topics
3. Application and deployment topics

---

## Beginner Topics

### 1. Variables and Basic Types
Focus: learning the basics of Python values, assignment, and primitive data types.

Topics covered:
- integers, floats, strings, booleans
- variables and naming conventions
- type basics and simple output

Goal:
- Understand how Python stores and uses data.

### 2. Functions and File I/O
Focus: writing reusable logic and handling files.

Topics covered:
- function definitions and return values
- parameters and arguments
- reading and writing text files
- organizing code into reusable blocks

Goal:
- Build small programs with cleaner logic and persistent file interactions.

### 3. Control Flow and Conditionals
Focus: making programs react to different conditions.

Topics covered:
- if / elif / else
- loops
- break and continue
- flow control patterns

Goal:
- Write programs that can make decisions and repeat tasks.

### 4. Collections and Dictionaries
Focus: working with grouped data structures.

Topics covered:
- lists
- tuples
- sets
- dictionaries
- iteration over collections

Goal:
- Store, access, and manipulate grouped information efficiently.

---

## Intermediate Topics

### 5. Object-Oriented Programming (OOP)
Focus: modeling real-world concepts with classes and objects.

Topics covered:
- classes and instances
- attributes and methods
- encapsulation
- inheritance
- polymorphism
- abstraction

Goal:
- Structure code into reusable, maintainable objects.

### 6. Hero CLI and Error Handling
Focus: building command-line tools and handling failures gracefully.

Topics covered:
- CLI interaction
- input/output handling
- exceptions and try/except
- user-friendly error messages

Goal:
- Create interactive scripts that behave predictably when things go wrong.

### 7. Pydantic Validation
Focus: enforcing clean data validation and schemas.

Topics covered:
- BaseModel usage
- field validation
- schema-driven inputs
- data parsing and reliability

Goal:
- Validate API data confidently and consistently.

### 8. SQLite
Focus: introducing database storage with SQLite.

Topics covered:
- database setup
- tables and rows
- ORM patterns
- in-memory and local database usage

Goal:
- Understand the basics of persistent data storage.

### 9. PostgreSQL
Focus: working with a production-style relational database.

Topics covered:
- PostgreSQL setup
- SQL interactions
- database connectivity
- relational data storage

Goal:
- Learn how application data is stored in real database systems.

### 10. Alembic Migration Management
Focus: versioning and evolving database schema safely.

Topics covered:
- migrations
- schema versioning
- upgrades and downgrades
- tracking database changes over time

Goal:
- Manage database changes professionally across application versions.

### 11. Uvicorn and FastAPI
Focus: building a modern web API with Python.

Topics covered:
- ASGI servers
- FastAPI app setup
- route creation
- request handling

Goal:
- Create a working API layer for web applications.

### 12. Asynchronous API Service
Focus: non-blocking request handling in Python services.

Topics covered:
- async functions
- await patterns
- asynchronous database usage
- scalable API interactions

Goal:
- Understand how modern Python services handle concurrent workloads efficiently.

### 13. Unit Testing
Focus: validating code behavior with automated tests.

Topics covered:
- pytest basics
- test structure
- assertions
- regression safety

Goal:
- Build trustworthy code by testing expected behavior.

---

## Application and Deployment Topics

### 14. Dockerfile and Containerization
Focus: packaging an app for deployment and reproducible environments.

Topics covered:
- Dockerfile creation
- dependency installation
- container runtime basics
- deployment-friendly setup

Goal:
- Run your project consistently across local and deployment environments.

---

## Suggested Progression

A solid learning path is:

Variables -> Functions -> Control Flow -> Collections -> OOP -> CLI/Error Handling -> Pydantic -> SQLite -> PostgreSQL -> Alembic -> FastAPI -> Async API -> Testing -> Docker

This sequence moves from Python fundamentals to backend systems, API development, testing, and containerization.
